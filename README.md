## Projects

### InterviewOS — AI Interview Preparation Platform *(in development)*

An AI system that diagnoses candidate weaknesses, trains recall under pressure, and builds interview readiness over time, going beyond a static question bank to deliver adaptive, personalized preparation.

**Stack:** LangChain · LangGraph · RAG · Next.js · TypeScript · PostgreSQL · Groq API
**Repository:** [pranavi015/interview-os](https://github.com/pranavi015/interview-os)

### Daywise — AI Study Planner

An AI-driven study planner that generates adaptive task schedules from a user's goals, pace, and deadlines.

- Built an adaptive engine generating 30+ study tasks from user goals, pace, and learning consistency
- Engineered dynamic scheduling that recalibrates tasks using streak tracking and activity data
- Implemented analytics across 4+ metrics: streaks, completions, study hours, and active days
- Developed 15+ REST APIs with pagination, validation, and centralized middleware

**Stack:** Next.js · TypeScript · Node.js · Express.js · PostgreSQL · Prisma · Tailwind CSS · Vercel
**Links:** [Repository](https://github.com/pranavi015/Daywise) · [Live Demo](https://day-wise-web.vercel.app/)

### MoodMeal — Mood-Aware Meal Recommendations

A meal recommendation platform that translates cravings and emotional context into healthier food choices.

- Built personalized food discovery using tagged taste history and mood-driven recommendation logic
- Engineered JWT-based security with role-based access control (RBAC) middleware and session validation
- Designed normalized MySQL schemas across 5+ entities
- Delivered 18+ REST endpoints for meal filtering, recommendations, and personalized search

**Stack:** Next.js · TypeScript · Express.js · Prisma ORM · MySQL · JWT · Tailwind CSS · Vercel
**Links:** [Repository](https://github.com/pranavi015/MoodMeal) · [Live Demo](https://mood-meal-web.vercel.app)
